# CoreSniper 🎯

Консольная утилита для Windows 10/11 на Python 3.13 (`ctypes` + `psutil`), которая анализирует топологию процессора, измеряет реальную производительность ядер с учётом буста и фоновых прерываний, и генерирует оптимальные маски соответствия (CPU Affinity) для **Process Lasso**.

Специально разработана для соревновательных игр (**Counter-Strike 2**, **Dota 2**, **Valorant**, **Apex Legends**), где стабильность 1% и 0.1% Low FPS критически зависит от изоляции игрового процесса от системных прерываний (DPC/ISR) и исключения задержек межъядерного взаимодействия (Cross-CCX Latency).

---

## ⚡ Особенности и возможности

1. **Глубокий анализ топологии (Win32 `GetLogicalProcessorInformationEx`)**:
   - Физические ядра и их SMT/HyperThreading пары.
   - Разбивка по группам общего кэша L3 (CCX / CCD на AMD Ryzen).
   - Поддержка Intel Hybrid Architecture (детекция P-Core / E-Core через `EfficiencyClass`).
   - 0-based нумерация потоков, на 100% совпадающая с отображением в **Process Lasso** и диспетчере задач.

2. **Стресс-тест скорости физических ядер**:
   - Привязка потока бенчмарка через Win32 API (`SetThreadGroupAffinity`).
   - Фиксированная вычислительная однопоточная нагрузка (3 прогона по 3 секунды с вычислением медианы).
   - Второй SMT-поток ядра остаётся в полном простое во избежание конкуренции за ресурсы конвейера.
   - Считывание реальной частоты и коэффициента буста ядра через системные счётчики Windows PDH (`% Processor Performance` и `Processor Frequency`).

3. **Профиль фоновой активности Windows**:
   - Мониторинг загрузки логических потоков в реальном времени (`psutil.cpu_percent(percpu=True)`).
   - Сбор системных счетчиков аппаратных прерываний (`% Interrupt Time`) и отложенных вызовов процедур (`% DPC Time`) через `pdh.dll`.
   - Расчёт средней и пиковой нагрузки (95-й перцентиль) по каждому потоку.

4. **Интеллектуальный скоринг и подбор ядер**:
   - `Итоговый скор = Скорость - Штраф фона - Штраф DPC/Прерываний - Штраф Ядра 0`.
   - **Штраф ядра 0**: ядро 0 гарантированно штрафуется, так как на нём крутятся системные таймеры и драйверы Windows.
   - **Изоляция внутри одного CCX**: пул из $K$ ядер (по умолчанию 4) подбирается **строго внутри одного блока L3/CCX**, что полностью устраняет задержки шины Infinity Fabric между разными CCX.
   - Два готовых профиля:
     - **«С SMT»** (оба потока каждого ядра) — максимальный суммарный FPS для многопоточных движков.
     - **«Без SMT»** (по 1 лучшему потоку на ядро) — максимальная плавность фреймтайма и минимальный инпут-лаг.

5. **Готовые данные для Process Lasso**:
   - Список номеров потоков (например: `8,9,10,11,12,13,14,15`).
   - Шестнадцатеричная маска аффинити (например: `0xFF00` или `0x5500`).
   - Экспорт отчёта в `report.txt` и `report.csv` рядом с исполняемым файлом.

6. **Безопасность**:
   - Никаких инжектов в память игры, хуков или сторонних неподписанных драйверов.
   - Работает исключительно со стандартными системными API Windows.

## 🛠 Сборка в автономный .exe (PyInstaller)

Для сборки проекта в один компактный бинарник `CoreSniper.exe`:

1. Просто запустите файл **`build.bat`** (двойным кликом в проводнике Windows или из консоли).
2. Скрипт автоматически:
   - Проверит окружение `.venv` и установит/обновит `pyinstaller`.
   - Очистит папки предыдущих сборок (`build/`, `dist/`).
   - Соберёт `dist\CoreSniper.exe` с встроенным UAC-манифестом администратора (`--uac-admin`), вырезав неиспользуемые библиотеки (`tkinter`, `unittest`, `xml` и др.).
   - Итоговый размер исполняемого файла: **~7.16 МБ**.

---

## 🚀 Запуск программы

- **Запуск собранного exe**: запустите файл `dist\CoreSniper.exe` (Windows автоматически запросит права Администратора).
- **Запуск исходного скрипта**:
  ```powershell
  .\.venv\Scripts\Activate.ps1
  python core_sniper.py
  ```

## 🎮 Настройка в Process Lasso

1. Откройте **Process Lasso**.
2. Запустите игру (`cs2.exe` или `dota2.exe`).
3. В списке активных процессов найдите игру и кликните **ПКМ**:
   - **Соответствие ЦП (CPU Affinity)** → **Всегда (Always)** → **Выбрать соответствие ЦП...**
4. Укажите потоки или введите Hex-маску из отчёта CoreSniper:
   - **Вариант «С SMT»** (например: потоки `8,9,10,11,12,13,14,15`, маска `0xFF00`)
   - **Вариант «Без SMT»** (например: потоки `8,10,12,14`, маска `0x5500`)
5. Нажмите **OK**. Process Lasso сохранит и будет автоматически применять эту привязку при каждом запуске игры.
